# موقع إبداع - خدمات التصوير والمونتاج والإعلان

موقع احترافي لعرض خدمات التصوير الفوتوغرافي، المونتاج، إدارة وسائل التواصل الاجتماعي، الحملات الإعلانية، المتاجر الإلكترونية، والتصاميم الإبداعية.

## 🚀 المميزات

### 📱 التصميم المتجاوب
- متوافق مع جميع الأجهزة (جوال، تابلت، كمبيوتر)
- تصميم عصري وأنيق
- تجربة مستخدم سلسة

### 🎨 الأقسام الرئيسية
- **الصفحة الرئيسية**: عرض احترافي للخدمات مع رسوم متحركة
- **الخدمات**: 6 خدمات رئيسية مع تفاصيل كاملة
- **معرض الأعمال**: عرض تفاعلي للمشاريع السابقة
- **من نحن**: معلومات عن الفريق والخبرات
- **تواصل معنا**: نموذج اتصال متقدم

### ⚡ التقنيات المستخدمة
- HTML5 Semantic Elements
- CSS3 مع Grid و Flexbox
- JavaScript ES6+
- Bootstrap 5
- AOS (Animate On Scroll)
- Font Awesome Icons

## 🔧 التخصيص

### تغيير الألوان
في ملف `css/style.css`:
```css
:root {
    --primary-color: #6366f1;    /* اللون الأساسي */
    --secondary-color: #8b5cf6;  /* اللون الثانوي */
    --accent-color: #ec4899;     /* اللون المميز */
}
```

### إضافة خدمات جديدة
1. أضف كرت خدمة جديد في قسم الخدمات في `index.html`
2. انسخ هيكل الكرت الحالي وعدل المحتوى
3. أضف التنسيقات إذا لزم الأمر

### تعديل معرض الأعمال
في ملف `js/script.js`، عدل مصفوفة `portfolioData`:
```javascript
const portfolioData = [
    {
        id: 1,
        title: 'عنوان المشروع',
        category: 'photography',
        image: 'images/project1.jpg',
        description: 'وصف المشروع'
    }
    // أضف المزيد من المشاريع
];
```
